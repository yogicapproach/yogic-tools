SYP Companion

version 0.8.2

A small pane above satyamyogaprasad.net pages: nested chapter navigation for 923 mapped books, deep links that open a book at its printed page, and reading tweaks. It stores your preferences on your own device and sends nothing anywhere.

Install

Firefox — desktop and Android listing pending

One build covers both. The add-on is going through Mozilla's review; this page will carry the install link as soon as it is live.

Chrome listing pending

Going through Chrome Web Store review. The link will appear here once published.

Edge — via the Chrome listing

Edge installs Chrome extensions directly. Open edge://extensions, turn on Allow extensions from other stores (bottom left), then use the Chrome link above once it is live. No separate Edge install is needed.

Install it now, before the listings are live

Download the matching zip from Releases and unzip it.

  1. Chrome / Edge: open chrome://extensions (or edge://extensions), turn on Developer mode, choose Load unpacked, and pick the unzipped folder.
  2. Firefox: open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on, and pick manifest.json. This one is removed when Firefox restarts — the store listing is the permanent route.

Privacy

Preferences are kept in your browser's own storage. The extension collects no personal data and transmits nothing — declared in its manifest as data_collection_permissions: none, which Firefox shows you at install time.
